OPÇÃO 1: Importar como Template (RECOMENDADO)
═════════════════════════════════════════════

1. No WordPress, vá para: Painel → Elementor → Modelos
2. Clique em "Importar Modelos"
3. Selecione o arquivo: elementor-template-peak-fresh.json
4. Clique em "Importar"
5. O template aparecerá na sua biblioteca
6. Crie uma nova página e aplique o template
7. Abra no editor Elementor para customizar


OPÇÃO 2: Copiar e Colar JSON (ALTERNATIVA)
═════════════════════════════════════════════

1. Abra o arquivo JSON em um editor de texto
2. Copie TODO o conteúdo
3. No Elementor, crie uma nova página
4. Abra o editor visual
5. Clique em Hambuger Menu (☰)
6. Selecione "Ferramentas" → "Exportar/Importar"
7. Cole o JSON e clique "Importar"

❌ "Arquivo não carrega"
   → Verifique se o arquivo está corrompido
   → Tente abrir com um editor de texto diferente
   → Confirme que é um JSON válido

❌ "Imagens não aparecem"
   → Confirme os caminhos: /images/nome-do-arquivo.png
   → Envie as imagens para a pasta /images do WordPress
   → Atualize os caminhos no Elementor

❌ "Cores estranhas"
   → Elementor pode ter sobrescrito as cores
   → Redefinir clicando no botão "Reset" no painel
   → Reaplique as cores manualmente
