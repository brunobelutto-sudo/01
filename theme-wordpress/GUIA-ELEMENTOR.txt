  GUIA COMPLETO ELEMENTOR - PEAK FRESH THEME
═══════════════════════════════════════════════════════════════════════════════

O Elementor é um editor visual que permite criar qualquer layout sem código.
Este guia mostra como usar o Elementor com o tema Peak Fresh.

═══════════════════════════════════════════════════════════════════════════════
1. INSTALANDO ELEMENTOR
═══════════════════════════════════════════════════════════════════════════════

1. Acesse: Painel → Plugins → Adicionar Novo
2. Pesquise por "Elementor"
3. Clique em "Instalar Agora"
4. Ative o plugin
5. Uma aba "Elementor" aparecerá no painel

═══════════════════════════════════════════════════════════════════════════════
2. CRIAR SUA PRIMEIRA PÁGINA COM ELEMENTOR
═══════════════════════════════════════════════════════════════════════════════

PASSO 1: Criar Página
────────────────────────────────────────────────────────────────────────────

1. Vá para: Painel → Páginas → Adicionar Nova
2. Digite o título (ex: "Meu Cardápio")
3. Clique no botão "Editar com Elementor"
4. Escolha um template ou comece vazio

PASSO 2: Explorar a Interface
────────────────────────────────────────────────────────────────────────────

TOPO:
  [← Voltar] [Salvar] [Atualizar] [Visualizar] [...Mais]

ESQUERDA: Painel com widgets
  └─ Elementos básicos
  └─ Imagens
  └─ Vídeos
  └─ Elementos avançados

CENTRO: Área de edição (onde você coloca elementos)

DIREITA: Opções do elemento selecionado

═══════════════════════════════════════════════════════════════════════════════
3. CONCEITOS BÁSICOS
═══════════════════════════════════════════════════════════════════════════════

ESTRUTURA ELEMENTOR:
│
├─ SEÇÃO (Section)
│  └─ COLUNA (Column)
│     └─ WIDGETS (Buttons, Heading, Image, etc)
│

SEÇÃO: Container maior que organiza o layout
COLUNA: Divisão horizontal dentro da seção
WIDGET: Elementos individuais (texto, imagem, botão)

═══════════════════════════════════════════════════════════════════════════════
4. WIDGETS ESSENCIAIS PARA PEAK FRESH
═══════════════════════════════════════════════════════════════════════════════

HEADING (Título)
──────────────────────────────────────────────────────────────────────────
Usar para: Títulos de seções, h1, h2, h3
Como usar:
  1. Clique em "Heading" no painel esquerdo
  2. Arraste para a página
  3. Edite o texto
  4. Configure tamanho, cor, alinhamento na direita

EXEMPLO:
  Heading 1: "Bem-vindo ao Peak Fresh"
  Heading 2: "Nosso Cardápio"

PARAGRAPH (Parágrafo/Texto)
──────────────────────────────────────────────────────────────────────────
Usar para: Textos descritivos, conteúdo
Como usar:
  1. Arraste "Paragraph" para a página
  2. Clique e escreva seu texto
  3. Formate em: negrito, itálico, links

BUTTON (Botão)
──────────────────────────────────────────────────────────────────────────
Usar para: CTAs (Chamar para ação)
Como usar:
  1. Arraste "Button" para a página
  2. Configure:
     - Texto: "Fazer Pedido"
     - Cor: Roxo (cor primária)
     - Link: WhatsApp (https://wa.me/seu_numero)
     - Tamanho: Médio ou Grande
     - Hover: Efeito ao passar mouse

EXEMPLO DE LINK:
  https://wa.me/5511999999999?text=Olá!%20Gostaria%20de%20fazer%20um%20pedido

IMAGE (Imagem)
──────────────────────────────────────────────────────────────────────────
Usar para: Fotos de produtos, banner
Como usar:
  1. Arraste "Image" para a página
  2. Clique em "Escolher Imagem"
  3. Upload da galera ou biblioteca
  4. Configure:
     - Tamanho
     - Borda
     - Sombra
     - Link (opcional)

ICON BOX (Ícone com Texto)
──────────────────────────────────────────────────────────────────────────
Usar para: Benefícios, características
Como usar:
  1. Arraste "Icon Box" para a página
  2. Selecione um ícone (✓, 🚚, etc)
  3. Adicione título e descrição
  4. Configure cores e alinhamento

EXAMPLE:
  Ícone: ✓
  Título: "Produto Premium"
  Descrição: "Açaí de alta qualidade"

TESTIMONIAL (Depoimento)
──────────────────────────────────────────────────────────────────────────
Usar para: Avaliações de clientes
Como usar:
  1. Arraste "Testimonial" para a página
  2. Preencha:
     - Texto do depoimento
     - Nome do cliente
     - Cargo/título
     - Imagem (opcional)
     - Classificação (estrelas)

IMAGE CAROUSEL (Galeria de Imagens)
──────────────────────────────────────────────────────────────────────────
Usar para: Múltiplas fotos de produtos
Como usar:
  1. Arraste "Image Carousel" para a página
  2. Clique em "Adicionar Itens"
  3. Upload múltiplas imagens
  4. Configure:
     - Número de itens por linha
     - Navegação
     - Autoplay

VIDEO (Vídeo)
──────────────────────────────────────────────────────────────────────────
Usar para: Demonstração de produtos, tutoriais
Como usar:
  1. Arraste "Video" para a página
  2. Cole URL do YouTube ou Vimeo
  3. Configure tamanho e proporção
  4. Reprodução automática (opcional)

5. ESTRUTURA DE PÁGINA IDEAL
═══════════════════════════════════════════════════════════════════════════════

1. HEADER (Topo)
   └─ Logo + Navegação (gerenciado pelo tema)

2. HERO SECTION
   └─ Heading grande
   └─ Paragrafo descritivo
   └─ 2 Botões (CTA)

3. BENEFÍCIOS
   └─ Heading: "Por que escolher Peak Fresh?"
   └─ 4x Icon Box

4. CARDÁPIO
   └─ Heading: "Nossos Produtos"
   └─ Image Gallery ou Cards

5. PROMOÇÃO
   └─ Fundo colorido (roxo)
   └─ Heading grande
   └─ Botão CTA

6. DEPOIMENTOS
   └─ Heading: "O que nossos clientes dizem"
   └─ 3x Testimonials

7. FOOTER (Rodapé)
   └─ Gerenciado pelo tema (não edite)

═══════════════════════════════════════════════════════════════════════════════
6. CONFIGURAÇÕES IMPORTANTES
═══════════════════════════════════════════════════════════════════════════════

CORES
──────────────────────────────────────────────────────────────────────────

Use estas cores do tema:
  Roxo Primário:    #7c2bbf (botões, links, destaque)
  Roxo Secundário:  #a064d2 (background suave)
  Fundo Claro:      #f8f4ff (background geral)
  Fundo Escuro:     #1a1823 (footer, seções escuras)
  Texto Escuro:     #2d1446 (títulos)
  Texto Claro:      #666666 (parágrafos)
  Verde WhatsApp:   #25d366 (botão WhatsApp)

TIPOGRAFIA
──────────────────────────────────────────────────────────────────────────

Use fonte: Inter (disponível no Google Fonts)
  Títulos:    800px (bold)
  Subtítulos: 600px (semibold)
  Texto:      400px (regular)

ESPAÇAMENTO
──────────────────────────────────────────────────────────────────────────

Use espaçamento consistente:
  Padding seção:  60px (desktop) / 30px (mobile)
  Gap elementos:  20-30px
  Margin títulos: 20px bottom

═══════════════════════════════════════════════════════════════════════════════
7. TEMPLATES PRÉ-PRONTOS (DENTRO DO ELEMENTOR)
═══════════════════════════════════════════════════════════════════════════════

No Elementor, você tem acesso a templates:

1. Clique em "Templates" (ícone de pasta)
2. Selecione "Elementor Templates"
3. Procure por categorias:
   - Hero sections
   - About
   - Services
   - Contact forms
   - Testimonials

RECOMENDAÇÃO: Use templates como base e customize com suas cores/conteúdo!

═══════════════════════════════════════════════════════════════════════════════
8. DICAS DE DESIGN
═══════════════════════════════════════════════════════════════════════════════

✓ CONSISTÊNCIA
  - Use sempre a mesma cor para botões CTA
  - Mantenha o mesmo tamanho de fonte para títulos

✓ ESPAÇAMENTO
  - Não coloque elementos muito juntos
  - Use seções com padding adequado

✓ MOBILIDADE
  - Sempre visualize no celular (ícone de smartphone no topo)
  - Teste layout em diferentes tamanhos

✓ HIERARQUIA
  - Títulos grandes para seções
  - Texto menor para descrições
  - Botões com alto contraste

✓ IMAGENS
  - Comprima imagens antes de upload
  - Use imagens de alta qualidade
  - Mantenha proporção 16:9

✓ CALLS TO ACTION (CTA)
  - Cores chamativas (roxo ou verde)
  - Texto claro e direto ("Compre Agora", "Faça Pedido")
  - Posicionamento estratégico (início, meio, fim)

═══════════════════════════════════════════════════════════════════════════════
9. EDITAR ELEMENTO
═══════════════════════════════════════════════════════════════════════════════

Quando você arrasta um widget, aparece uma caixa com 3 linhas:

LINHA 1 (Configurações gerais):
  • Duração/Transição
  • Efeitos
  • Espaçamento

LINHA 2 (Estilo - aparece ao lado direito):
  • Cor
  • Tipografia
  • Sombra
  • Borda

LINHA 3 (Avançado):
  • Classes CSS customizadas
  • IDs
  • Atributos

═══════════════════════════════════════════════════════════════════════════════
10. RESPONSIVIDADE (Mobile)
═══════════════════════════════════════════════════════════════════════════════

Ao editar, você verá 3 ícones no topo:
  🖥️ Desktop (padrão)
  📱 Tablet
  📱 Mobile

BOAS PRÁTICAS:
1. Design para mobile primeiro
2. Use colunas que se reorganizam
3. Teste em diferentes tamanhos
4. Botões grandes em mobile (pelo menos 44px)

EXEMPLO:
  Desktop: 3 colunas
  Tablet:  2 colunas
  Mobile:  1 coluna

═══════════════════════════════════════════════════════════════════════════════
11. ANIMAÇÕES
═══════════════════════════════════════════════════════════════════════════════

Para adicionar animações:

1. Selecione um elemento
2. Vá para "Avançado" (direita)
3. Abra "Animações de Entrada"
4. Escolha:
   - Fade In (desaparecer)
   - Slide Up (deslizar para cima)
   - Zoom In (aproximar)

RECOMENDAÇÃO: Use com moderação para não ficar poluído!

14. EXEMPLO PRÁTICO: CRIAR SEÇÃO DE PRODUTO
═══════════════════════════════════════════════════════════════════════════════

1. Crie uma nova SEÇÃO
2. Coloque 2 COLUNAS (50% | 50%)

COLUNA 1 (Imagem):
  └─ Widget: Image
  └─ Upload foto do produto
  └─ Configure tamanho

COLUNA 2 (Conteúdo):
  ├─ Heading: "Açaí Tropical"
  ├─ Paragraph: Descrição do produto
  ├─ Icon Box com preço
  └─ Button: "Pedir Agora"
     └─ Link: https://wa.me/...

3. Configure cores e espaçamento
4. Teste no mobile
5. Salve!

16. TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

PROBLEMA: Elementor não carrega
SOLUÇÃO: 
  1. Limpe cache do navegador
  2. Desative outros plugins temporariamente
  3. Atualize o Elementor

PROBLEMA: Elemento não aparece no mobile
SOLUÇÃO:
  1. Vá para visualização mobile
  2. Ajuste configurações de responsividade
  3. Use "Mostrar/Ocultar" por dispositivo

PROBLEMA: Layout desalinhado
SOLUÇÃO:
  1. Verifique coluna (deve somar 100%)
  2. Ajuste margens/paddings
  3. Use grid ao invés de colunas
