📌 ANATOMIA DO JSON DO ELEMENTOR:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Estrutura básica:

{
  "version": "0.4",                    ← Versão do Elementor
  "title": "Nome do Template",         ← Nome que aparece
  "description": "Descrição",          ← Descrição
  "author": "Peak Fresh",              ← Seu nome/marca
  "type": "page",                      ← Tipo de template
  "content": [                         ← Conteúdo começa aqui
    { seção 1 },
    { seção 2 },
    ...
  ]
}


🏗️ HIERARQUIA DOS ELEMENTOS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

         PÁGINA
          │
    ┌─────┼─────┐
    │     │     │
   SEÇÃO SEÇÃO SEÇÃO
    │     │     │
   CONTAINER (agrupador)
    │
  ┌─┴──────┬──────┬──────┐
  │        │      │      │
 COL    COL    COL    COL
  │
 WIDGET


EXEMPLO:

Page (página inteira)
  └─ Section (hero-section)
      └─ Container (div wrapper)
          ├─ Widget (heading - título)
          ├─ Widget (text-editor - descrição)
          └─ Widget (button - botão CTA)


🔧 TIPOS DE ELEMENTOS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1️⃣  SECTION (Seção = linha completa)
    ├─ elType: "section"
    ├─ settings: { background, padding, etc }
    ├─ elements: [ array de elementos dentro ]
    └─ Exemplo: Hero, benefícios, cardápio, footer


2️⃣  CONTAINER (Agrupador = caixa com flexbox)
    ├─ elType: "container"
    ├─ settings: { width, layout, etc }
    ├─ elements: [ array de colunas/elementos ]
    └─ Exemplo: Caixa com múltiplas colunas


3️⃣  COLUMN (Coluna = espaço dentro de container)
    ├─ elType: "column"
    ├─ settings: { width: "33.333%" }
    ├─ elements: [ widgets dentro da coluna ]
    └─ Exemplo: 3 colunas de produtos


4️⃣  WIDGET (Widget = elemento visual final)
    ├─ elType: "widget"
    ├─ widgetType: "heading" (tipo específico)
    ├─ settings: { conteúdo e estilos }
    └─ Exemplo: Títulos, textos, botões, imagens


🎨 TIPOS DE WIDGETS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

WIDGET: heading (TÍTULOS)
─────────────────────────
Propriedades:
{
  "widgetType": "heading",
  "settings": {
    "title": "Texto do título",
    "header_size": "h1" (h1, h2, h3, h4, h5, h6),
    "text_color": "#FFFFFF",
    "typography_font_size": {
      "unit": "px",
      "size": 42
    },
    "typography_font_weight": "700"
  }
}


WIDGET: text-editor (TEXTOS)
────────────────────────────
{
  "widgetType": "text-editor",
  "settings": {
    "editor": "Conteúdo com HTML permitido",
    "text_color": "#B0B0B0",
    "typography_font_size": {
      "unit": "px",
      "size": 16
    }
  }
}


WIDGET: button (BOTÕES)
──────────────────────
{
  "widgetType": "button",
  "settings": {
    "text": "Clique aqui",
    "link": {
      "url": "https://exemplo.com"
    },
    "button_type": "primary" (primary, success, danger, etc),
    "size": "lg" (md, lg, xl),
    "background_color": "#7C2BBF"
  }
}


WIDGET: image (IMAGENS)
──────────────────────
{
  "widgetType": "image",
  "settings": {
    "image": {
      "url": "/images/foto.png"
    },
    "caption": "Descrição",
    "image_size": "full"
  }
}


WIDGET: icon (ÍCONES)
────────────────────
{
  "widgetType": "icon",
  "settings": {
    "icon": "fas fa-leaf",
    "icon_color": "#7C2BBF",
    "icon_size": {
      "unit": "px",
      "size": 48
    }
  }
}


WIDGET: nav-menu (MENU)
──────────────────────
{
  "widgetType": "nav-menu",
  "settings": {
    "menu": "main-menu",
    "layout": "horizontal",
    "alignment": "center"
  }
}


🎨 PROPRIEDADES DE ESTILO COMUNS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CORES:
──────
"text_color": "#FFFFFF" → cor do texto
"background_color": "#1a1823" → cor de fundo
"border_color": "#7C2BBF" → cor da borda


ESPAÇAMENTO:
────────────
"margin_top": "20px"
"margin_bottom": "40px"
"margin_left": "10px"
"margin_right": "10px"
"padding": "20px"
"padding_top": "20px"


TAMANHO DE FONTE:
─────────────────
"typography_font_size": {
  "unit": "px",
  "size": 16
}

"typography_font_weight": "400" (300, 400, 500, 600, 700, 800, 900)


ALINHAMENTO:
────────────
"text_align": "center" (left, center, right, justify)
"alignment": "center" (para flexbox)


BACKGROUND (FUNDO):
────────────────────
// Cor sólida:
"background_background": "classic"
"background_color": "#1a1823"

// Gradiente:
"background_background": "gradient"
"background_gradient_type": "linear"
"background_gradient_angle": "45"
"background_gradient_stops": [
  { "color": "#7C2BBF", "position": "0" },
  { "color": "#5A1F8F", "position": "100" }
]

// Imagem:
"background_background": "image"
"background_image": { "url": "/images/bg.png" }
"background_size": "cover"
"background_position": "center center"


DIMENSÕES:
──────────
"width": "100%" (para widgets)
"width": "boxed" (para containers)
"content_width": "1200px"
"min_height": "600px"

🔄 IDS ÚNICOS:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Cada elemento DEVE ter um "id" único:
- "id": "hero-section" ✓
- "id": "benefit-1-icon" ✓
- "id": "product-card-3" ✓

Não pode repetir IDs!
Se repetir, o Elementor vai gerar conflitos.


📐 RESPONSIVIDADE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Você pode adicionar breakpoints diferentes no JSON:

{
  "settings": {
    // Desktop
    "typography_font_size": { "unit": "px", "size": 42 },
    // Tablet
    "_tablet_typography_font_size": { "unit": "px", "size": 32 },
    // Mobile
    "_mobile_typography_font_size": { "unit": "px", "size": 24 }
  }
}

Prefixos:
- Nenhum prefixo = Desktop
- "_tablet_" = Tablet
- "_mobile_" = Mobile


✅ VALIDAÇÃO DO JSON:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Ferramentas online para validar:
- jsonlint.com
- jsonformatter.org
- nodejs.org (npm install jsonlint)

Se o JSON não importa no Elementor:
1. Valide no JSONLint
2. Procure por vírgulas faltando
3. Aspas mal colocadas
4. Parênteses desbalanceados


🚀 EDITANDO O JSON MANUALMENTE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Se quiser editar o JSON antes de importar:

1. Abra em editor de texto (VS Code, Notepad++)
2. Faça as mudanças
3. Valide no JSONLint
4. Salve como .json
5. Importe no Elementor

Mudanças comuns:
- Trocar URLs
- Mudar cores (HEX)
- Alterar textos
- Ajustar tamanhos


📞 ERROS COMUNS NO JSON:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ Vírgula faltando:
   "color": "#7C2BBF"    ← Falta vírgula se tiver mais propriedade
   "size": 48
   
✓ Correto:
   "color": "#7C2BBF",   ← Tem vírgula
   "size": 48

❌ Aspas simples:
   'color': '#7C2BBF'    ← JSON não aceita aspas simples

✓ Correto:
   "color": "#7C2BBF"    ← Aspas duplas

❌ Propriedade com espaço:
   "font size": 16       ← Sem espaços em nomes

✓ Correto:
   "font_size": 16       ← Usar underscore
