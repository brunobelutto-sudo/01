🚀 COMO USAR ELEMENTOR
═══════════════════════════════════════════════════════════════════════════════

1. Instale o plugin Elementor
2. Crie uma página nova
3. Clique em "Editar com Elementor"
4. Arraste elementos (widgets) para a página
5. Configure cores, textos, imagens
6. Salve a página

VOCÊ NÃO PRECISA:
  ✗ Editar código PHP
  ✗ Tocar em arquivos do tema
  ✗ Conhecer HTML/CSS

TUDO PODE SER FEITO:
  ✓ Via editor visual do Elementor
  ✓ Clicando e arrastando elementos
  ✓ Digitando textos e subindo imagens

🎯 GUIA DE EDIÇÃO RÁPIDA
═══════════════════════════════════════════════════════════════════════════════

MUDAR COR ROXO PARA AZUL:
  1. Abra: style.css
  2. Encontre: --purple-primary: #7c2bbf;
  3. Mude para: --purple-primary: #2563eb;
  4. Salve (Ctrl+S)
  5. Recarregue o site (F5)

ADICIONAR NÚMERO WHATSAPP:
  1. Abra: footer.php
  2. Encontre: 5511999999999
  3. Mude para SEU NÚMERO
  4. Salve
  5. Recarregue o site

MUDAR TEXTO DO FOOTER:
  1. Abra: footer.php
  2. Procure por: get_theme_mod('peak_fresh_footer
  3. Mude o texto padrão
  4. Salve

ADICIONAR NOVA PÁGINA COM ELEMENTOR:
  1. Painel → Páginas → Adicionar Nova
  2. Titulo: "Seu Titulo"
  3. Clique: "Editar com Elementor"
  4. Arraste elementos
  5. Salve

❓ PERGUNTAS FREQUENTES

P: Preciso saber código para usar este tema?

R: SIM! Edite style.css ou use o Customizer.
