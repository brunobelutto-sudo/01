Um tema WordPress moderno e totalmente customizável para lojas de açaí e bebidas saudáveis.

== Description ==

Peak Fresh é um tema WordPress premium desenvolvido especificamente para pequenas e médias
empresas de açaí, smoothies e bebidas saudáveis. Com suporte completo ao Elementor,
você pode customizar cada detalhe sem escrever uma linha de código.

== Características ==

✓ 100% Responsivo (Mobile, Tablet, Desktop)
✓ Compatível com Elementor (grátis)
✓ Design Moderno e Atrativo
✓ Integração WhatsApp
✓ Custom Post Type para Produtos
✓ Menu Mobile Inteligente
✓ Otimizado para SEO
✓ Rápido e Leve
✓ Suporte a Dark Mode (CSS pronto)
✓ Animações Suaves

== Installation ==

1. Upload o arquivo .zip do tema via Painel → Aparência → Temas → Adicionar Novo
2. Ou extraia em wp-content/themes/ via FTP
3. Ative o tema em Painel → Aparência → Temas
4. Configure em Painel → Aparência → Personalizar

== Requisitos ==

- WordPress 6.0+
- PHP 7.4+
- Elementor (recomendado)

== Plugins Recomendados ==

- Elementor (para edição visual)
- WooCommerce (para loja online)
- Yoast SEO (otimização de busca)
- Contact Form 7 (formulários)

== Cores Padrão ==

- Roxo Primário: #7c2bbf
- Roxo Secundário: #a064d2
- Fundo Claro: #f8f4ff
- Fundo Escuro: #1a1823
- Verde WhatsApp: #25d366

Todas as cores podem ser customizadas no arquivo style.css ou via Elementor.

== Estrutura de Arquivos ==

style.css            - Estilos CSS (customize aqui)
functions.php        - Funções e hooks do tema
header.php           - Cabeçalho do site
footer.php           - Rodapé do site
index.php            - Página padrão
front-page.php       - Página inicial
js/main.js          - JavaScript customizado
template-parts/     - Templates reutilizáveis

== Customização ==

1. CORES: Edite as variáveis em style.css (:root)
2. LOGO: Painel → Aparência → Personalizar → Identidade do site
3. MENUS: Painel → Aparência → Menus
4. CONTEÚDO: Use o Elementor para editar páginas
