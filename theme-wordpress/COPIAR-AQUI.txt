═══════════════════════════════════════════════════════════════════════════════
🚀 OPÇÃO 1: INSTALAÇÃO FÁCIL (RECOMENDADO)
═══════════════════════════════════════════════════════════════════════════════

1. BAIXE TODOS OS ARQUIVOS DESTA PASTA

2. COMPACTE EM .ZIP
   └─ Selecione todos os arquivos
   └─ Clique direito → Comprimir (ou "7-Zip → Criar arquivo")
   └─ Nome: "peak-fresh.zip"

3. INSTALE NO WORDPRESS
   └─ Painel → Aparência → Temas
   └─ Clique em "Adicionar Novo"
   └─ Clique em "Enviar tema"
   └─ Selecione o arquivo .zip
   └─ Clique em "Instalar Agora"
   └─ Clique em "Ativar"

PRONTO! O tema está instalado!

🔧 OPÇÃO 2: INSTALAÇÃO VIA FTP (AVANÇADO)
═══════════════════════════════════════════════════════════════════════════════

1. CONECTE VIA FTP
   └─ Use Filezilla, WinSCP ou similar
   └─ Dados: Fornecidos pela sua hospedagem

2. NAVEGUE PARA
   └─ /public_html/wp-content/themes/

3. CRIE PASTA

   └─ Nome: "peak-fresh"

4. FAÇA UPLOAD DOS ARQUIVOS
   └─ Todos os arquivos .php, .css, .js
   └─ Dentro da pasta "peak-fresh"

5. ATIVE NO WORDPRESS
   └─ Painel → Aparência → Temas
   └─ Procure "Peak Fresh"
   └─ Clique em "Ativar"

✂️  PASSO-A-PASSO: COMO COPIAR CADA ARQUIVO
═══════════════════════════════════════════════════════════════════════════════

Para CADA arquivo abaixo:

1. Abra o arquivo .txt no seu computador (Bloco de Notas, VS Code, etc)
2. Ctrl+A para selecionar tudo
3. Ctrl+C para copiar
4. No WordPress:
   └─ Painel → Aparência → Editor de Arquivo de Tema
   └─ Procure pelo arquivo na lista da direita
   └─ Clique para abrir
   └─ Ctrl+A para selecionar tudo
   └─ Ctrl+V para colar
   └─ Clique em "Atualizar Arquivo"

OU VIA FTP:

1. Abra o arquivo .txt no seu editor
2. Copie o conteúdo
3. Crie um novo arquivo no FTP:
   └─ Clique direito → Criar Arquivo
   └─ Nome: "style.css" (ou qual for)
   └─ Edite: Clique direito → Editar
   └─ Cole o conteúdo
   └─ Salve

⚠️  ERROS COMUNS E SOLUÇÕES
═══════════════════════════════════════════════════════════════════════════════

ERRO: "Arquivo functions.php está faltando"
SOLUÇÃO: 
  └─ Você copiou o arquivo?
  └─ Está na pasta correta?
  └─ Tente copiar novamente

ERRO: "Página em branco"
SOLUÇÃO:
  └─ Ative modo debug:
  └─ Abra wp-config.php
  └─ Procure: define('WP_DEBUG', false);
  └─ Mude para: define('WP_DEBUG', true);
  └─ Verifique erros em wp-content/debug.log

ERRO: "Tema não aparece"
SOLUÇÃO:
  └─ Compactou os arquivos em .zip?
  └─ O .zip contém pasta "peak-fresh"?
  └─ Tente instalar novamente

ERRO: "Elementor não funciona"
SOLUÇÃO:
  └─ Instalou o plugin Elementor?
  └─ Ativou o plugin?
  └─ Atualize Elementor para última versão
