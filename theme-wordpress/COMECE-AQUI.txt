┌─────────────────────────────────────────────────────────────────────────────┐
│ 🔧 COMO CUSTOMIZAR (GUIA RÁPIDO)                                            │
└─────────────────────────────────────────────────────────────────────────────┘

MUDAR CORES:
  1. Abra: style.css
  2. Procure: :root {
  3. Mude os valores HEX (#7c2bbf)
  4. Salve

MUDAR LOGO:
  1. Painel → Aparência → Personalizar
  2. Identidade do Site → Logo
  3. Upload de uma imagem

MUDAR TEXTOS DO FOOTER:
  1. Abra: footer.php
  2. Procure: 'peak_fresh_footer_col1_text'
  3. Mude o texto padrão
  4. Salve

ADICIONAR MENU:
  1. Painel → Aparência → Menus
  2. Crie novo menu
  3. Adicione itens
  4. Atribua ao "Menu Principal"

CRIAR PÁGINA NO ELEMENTOR:
  1. Painel → Páginas → Adicionar Nova
  2. Título
  3. Clique em "Editar com Elementor"
  4. Arraste elementos
  5. Salve

┌─────────────────────────────────────────────────────────────────────────────┐
│ 🎓 DICAS PARA INICIANTES                                                    │
└─────────────────────────────────────────────────────────────────────────────┘

1. NÃO tenha medo de experimentar
   → Você pode desfarzer tudo com Ctrl+Z

2. Use o Elementor para tudo
   → Evite editar código enquanto aprende

3. Faça backup regularmente
   → Use UpdraftPlus ou similar

4. Teste no celular
   → Elementor tem ícone para visualizar mobile

5. Não coloque muitos plugins
   → Deixa o site lento

6. Comprima imagens
   → Antes de fazer upload ao WordPress

7. Use as cores do tema
   → Mantenha consistência visual

8. Assista tutoriais Elementor
   → YouTube tem centenas de videos úteis

┌─────────────────────────────────────────────────────────────────────────────┐
│ 🆘 ALGO DEU ERRADO?                                                         │
└─────────────────────────────────────────────────────────────────────────────┘

PÁGINA EM BRANCO:
  └─ Ative modo debug em wp-config.php
  └─ Verifique erro em logs do servidor

ELEMENTOR NÃO CARREGA:
  └─ Atualize o Elementor
  └─ Limpe cache do navegador
  └─ Desative plugins um por um

IMAGENS NÃO APARECEM:
  └─ Verifique permissões de pasta (chmod 755)
  └─ Tente fazer upload novamente
  └─ Limpe cache

MENU NÃO APARECE:
  └─ Você criou um menu?
  └─ Atribuiu ao "Menu Principal"?
  └─ Verifique em Aparência → Menus
